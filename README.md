# Research Assistant for Zotero — update status

This public repository serves a small, machine-readable status document for
the invitation-only Research Assistant for Zotero beta.

It contains no plugin source, XPI installer, tester information, credentials,
analytics, or private release link. The plugin downloads only `beta.json`,
validates its exact schema and add-on identity, and compares versions locally.
Invited testers obtain installers through the separate private beta Releases
page in their normal browser.

The endpoint is informational. It cannot make the plugin install software or
choose a browser destination.
